# RPS RTS — Backlog Index

Each backlog is owned by one discipline so a specialist agent (or person) can work from it without reading the others. Cross-links use `→ [area]#ID`.

| Backlog | Owner skill set | File |
|---|---|---|
| Economy & Market | systems / economy design, balancing math | `docs/backlog/economy.md` |
| Military & Conflict | combat design, RTS unit design | `docs/backlog/military.md` |
| Diplomacy & Alliances | social systems design | `docs/backlog/diplomacy.md` |
| AI Governors (bots) | game AI, strategy policies | `docs/backlog/ai-governors.md` |
| Game Architecture | engineering: sim core, action model, client, runner | `docs/backlog/game-architecture.md` |
| System Infrastructure | engineering: hosting, servers, persistence, sharding, volunteer nodes | `docs/backlog/infrastructure.md` |
| Factions, Art & Lore | art direction, narrative | `docs/backlog/factions-art.md` |
| Future Ideas (parking lot) | anyone | `docs/backlog/ideas.md` |

**Status tags:** `[now]` in progress · `[next]` ready · `[later]` needs design · `[idea]` unvetted

**Rule of thumb:** a mechanic enters the sim only after it has a line in the relevant backlog with a question it answers ("does X make trade more interesting?").
